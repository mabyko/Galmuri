# Galmuri · 갈무리

**여러 프로필의 북마크를 한곳에서 다듬고, 브라우저에 반영하세요.**

[English](README.md) · 한국어 · [日本語](README.ja.md) · [简体中文](README.zh-Hans.md)

Galmuri는 개발 중인 **SwiftUI 네이티브 macOS 북마크 편집기**입니다. 여러 Chrome 프로필을 영속적인 작업본으로 가져오고, 앱 편집 내용과 최신 원본을 병합해 검토합니다. 기존 파일 기반 작업본에는 확장 프로그램이 필요하지 않습니다. 선택형 프로필별 확장 브리지는 실행 중인 Chrome의 북마크를 읽고, 작업본 편집·3-way 검토와 명시적으로 허용한 전용 테스트 환경의 복원 가능한 반영을 지원합니다.

## 현재 상태

설정 → 실험실 → API 연결 관리 및 편집기에서 별도 API 작업과 프로필 승인을 진행합니다. 확장 설치 안내에서 앱과 맞는 ZIP을 저장할 수 있고, `Bridge/extension`에는 향후 GitHub 다운로드용 Release 폴더를 준비했습니다. 파일 직접 반영도 실험실로 옮겼으며 앱 소유의 합성 테스트 파일만 지원합니다. Chrome을 종료해도 자동 반영되지 않습니다. [실험실·설치 안내](docs/labs.md)를 참고하세요. 확장은 `bookmarks`, `nativeMessaging`, `storage` 권한을 사용하며 웹사이트 권한은 없습니다. 일반 연결은 Chrome 원본에 대해 읽기 전용이며, 명시적으로 표시한 전용 테스트 연결만 반영할 수 있습니다. 추가·이름 변경·이동·정렬, 복구 폴더로의 삭제, 검토 후 복원, 중단 상태 확인과 Chrome 재시작을 전용 Chrome for Testing에서 확인했습니다. [API 설정·동작·제한](docs/chrome-api-workspace.md)을 참고하세요.

Release27에서 큰 진행·결과 메시지 전송 문제를 수정하고, 중단 확인·현재 상태 복구와 API 뒤로·앞으로·상위 이동, 다중 선택·드래그 대상을 추가했습니다. 화면은 차분한 회색 바탕과 파란색 액션·선택 표시로 정리했습니다. 코어 병합 성능 측정과 제한은 [네이티브 개편](docs/native-refinement.md)에 기록했습니다. 실제 사용자 프로필 쓰기, 접근성 실물 검수와 실제 Chrome 설치·동기화 검증은 아직 제한합니다.

Release28에서는 삭제 예정 항목과 폴더 내용 변경도 반영 전 변경 목록에 표시하고, 검토 후 복원할 수 있습니다. 연결 정보는 별도 창으로 열리며 기존 편집 내용과 작업본 호환성을 유지합니다.

Release30에서는 실험실의 두 기능을 각각 켜고 끌 수 있으며 기본값은 꺼짐입니다. API 편집을 켜면 선택된 프로필의 디스크 확장 설치 기록을 확인하고, 활성화·연결 여부는 별도로 안내합니다. 변경사항 검토는 가져온 원본 사본과 작업본을 비교하며 새로고침 병합과 구분합니다. 기능을 꺼도 편집 내용은 유지되고 실제 프로필 쓰기 제한은 그대로입니다.

Release31에서는 메인 사이드바와 최초 연결 화면에 설정 버튼을 추가하고, 설정 안에 일반·실험실 메뉴를 나눴습니다. API 편집을 켜면 Galmuri에 등록된 모든 프로필을 한 번 검사하고, 이후에는 수동으로 재검사합니다. 프로필별 기록·검사 시각을 표시하며 편집 화면의 선택 변경으로 자동 재검사하지 않습니다. 미등록 프로필을 찾지 않으며 설치 기록과 활성화·연결은 구분합니다.

Release32에서는 코드 전수 점검 결과를 반영했습니다. HTML 내보내기는 http(s)가 아닌 주소를 건너뛰고 개수를 알려주며, 그런 북마크도 이름을 바꿀 수 있습니다. API 편집은 바뀐 주소를 정규화하고, 화면에 보이는 순서대로 이동하며, 복원 기록을 하나만 유지합니다. 세션 만료 직전에는 반영을 시작하지 않고 끝난 작업 파일을 지웁니다. 편집할 때마다 모든 원본을 다시 읽지 않으며, 변화 없는 편집은 저장하지 않습니다. 실행 취소는 100단계까지, ‘새로 고침 전’ 보관 사본은 최신 10개만 유지합니다. ‘연결 해제’와 ‘가져오기 전’ 보관 사본은 자동으로 지우지 않습니다.

Release33에서는 점검 후속 작업을 마무리했습니다. 검토 읽기·병합·반영·복원은 메인 스레드 밖에서 실행되고, 진행 중에는 시트를 닫아 중단할 수 없으며, 복원은 실제로 끝났는지 알려줍니다. API 편집은 바뀐 주소를 국제 도메인을 포함해 Chrome과 같은 형태로 저장하고, Chrome이 바꿀 주소는 거부합니다. 세션이 2분 미만 남았거나 저장된 주소가 Chrome 형태가 아니면 반영을 처음부터 거절합니다. 연결되지 않은 암호화 저장소 실험 코드를 제거했고, 메인 표는 더 이상 AppKit 재진입 경고를 남기지 않습니다.

네이티브 로컬 개발을 진행하고 있습니다. 사이드바·표 편집, 중첩 폴더, 북마크 편집, 다중 선택 이동·같은 프로필 내 드래그 이동, 정렬, 검색, 같은 URL 보기, 제외·되돌리기, 작업본 JSON 백업·불러오기, 전체·폴더 하위 Netscape HTML 내보내기를 구현했습니다. Swift의 실제 3-way 병합 결과로 충돌 선택과 최종 검토를 진행합니다. 원본 백업·교체·복원은 현재 **앱이 만든 합성 테스트 파일에만** 허용합니다.

파일 방식으로 연결한 외부 Chrome 프로필의 원본은 읽기 전용이며, 폴더 접근이 끊겨도 앱 작업본은 편집할 수 있습니다. 원래 폴더를 다시 선택하면 편집 내용을 초기화하지 않고 연결을 복구합니다. 반영·복원 승인은 원본 바이트와 파일 식별 정보에 묶이며, 손상된 기록 때문에 정상 백업을 숨기지 않습니다. **암호화된 북마크 지원은 보류했습니다.** 설정 → 실험실에는 꺼진 상태의 비활성 ‘지원 예정’ 항목만 있으며, 키체인 접근이나 암호화 저장소의 앱 연결은 구현하지 않습니다. 앱과 분리된 코어 실험의 소스는 2026-11-12에 제거했으며, [과거 검증 기록](docs/encrypted-store-adapter.md)은 그대로 보존합니다. 이 실험은 앱 지원 기능이 아니었습니다. 외부 파일 직접 쓰기는 비활성화되어 있으며, 위의 별도 API 테스트로 이 제한을 해제하지 않습니다. 평문 저장소의 권한·브라우저 종료 확인, 브라우저 반영·동기화, 네이티브 접근성·언어, 배포 검증은 남아 있습니다. 직접 반영이 제품 목표이며 HTML 내보내기가 이를 대체하지 않습니다. 같은 URL의 북마크도 별도 항목으로 유지합니다.

새 작업 공간은 브라우저 연결 화면으로 시작합니다. Chrome 연결을 누르면 기본 위치를 일반 권한으로 확인하고, 접근 가능하면 곧바로 프로필 이름을 보여줍니다. 접근이 필요하거나 위치가 다를 때만 앱의 안내에서 폴더 선택을 진행합니다. 선택한 지원 가능 프로필만 추가하며, 이전 테스트 프로필과 편집 내용은 보존하고 별도로 열 수 있습니다. 편집·이동·삭제 버튼과 각 행의 연필 버튼, 되돌리기를 제공합니다. 단일 북마크는 삭제 후 바로 되돌릴 수 있고, 폴더·다중 삭제는 대상과 전체 영향 범위를 먼저 보여줍니다. [편집 UX 결정](docs/editing-ux.md)을 참고하세요.

GitHub 공개와 공개 배포는 로컬 검토 이후로 보류합니다. 완료 범위와 막힌 항목은 [TASKS.md](TASKS.md), 검증 근거와 한계는 [검증 기록](docs/validation.md)에 있습니다.

연결 화면에서 Chrome 또는 Ego Lite를 고르면 해당 브라우저의 기본 위치를 찾습니다. Ego Lite는 평문 북마크에 한정된 읽기 전용 시험 연결이며, 최신 상태와 실제 브라우저 호환성은 아직 검증하지 않았습니다. 폴더 선택은 접근 권한이나 별도 위치가 필요한 경우의 보조 수단이며, macOS 승인이 필요할 수 있습니다.

브라우저 접근이 거부되면 먼저 폴더 승인 안내를 보여줍니다. 표준 선택 창에서 브라우저 데이터 폴더가 미리 열리므로 위치를 바꾸지 않고 이 폴더 접근 허용을 누르면 됩니다. 확인 후 프로필 정보를 읽고 성공해야 다음 화면으로 넘어갑니다. 해당 macOS의 Chrome에서 확인한 폴더도 거부될 때만 시스템 설정을 안내하며, 일반 파일 권한 오류는 따로 처리합니다. 기존 작업은 보존합니다. 실제 보호 폴더 승인과 권한 유지는 아직 미검증입니다.

포인터는 움직이지만 클릭·키보드 입력에 반응하지 않았다는 제보 이후 설정 항목 자동 찾기를 철회했습니다. Release 17에서 손쉬운 사용 구현과 권한 요청을 제거했으며 이 방식은 재도입하지 않습니다. 시스템 설정 안내의 버튼은 파일 및 폴더 화면만 열고, Galmuri를 찾아 펼치는 작업은 직접 합니다. 연결에 추가 손쉬운 사용·자동화 권한은 필요 없습니다. 당시 증상의 원인은 아직 미확정입니다.

프로필 선택 화면에서 발견된 북마크 파일과 수정 시각을 확인할 수 있습니다. 암호화·다른 저장소 파일이 함께 있어도 읽을 수 있는 평문 Bookmarks는 선택할 수 있으며, 다른 파일의 내용은 제외합니다. 평문 파일 없음과 읽기 불가를 구분하고 사유를 표시합니다. 파일 종류는 이름에 따른 분류이고 수정 시각이 Chrome의 최신 내용을 보장하지는 않습니다. 선택한 평문은 가져올 때 검증하며 원본 쓰기 제한은 유지합니다.

## 로컬 실행

macOS, Xcode 명령줄 도구, Swift 6 이상이 필요합니다. 빌드 대상은 macOS 14이며, 실제 확인한 OS·도구 버전은 검증 기록에 있습니다.

```sh
swift test
python3 scripts/check-localization.py
scripts/build-local.sh release
open "build/release/Galmuri.app"
```

스크립트는 `forked.galmuri.local.release` 식별자로 ad-hoc 서명한 로컬 Release를 만듭니다. Debug는 기존 `forked.galmuri.local` ID와 별도 데이터, 파란 DEV 아이콘을 사용합니다. 빌드만으로 Applications 설치나 Apple 팀 등록을 하지 않습니다. 첫 실행은 Chrome 연결 화면이며, 합성 데이터는 명시적인 QA·샘플 실행에서만 만듭니다. 격리 작업 공간, 데이터 경로, 네이티브 화면 확인 방법은 [로컬 개발 안내](docs/local-development.md)를 참고하세요. 실제 원본을 테스트 자료로 쓰지 마세요.

## 반영 흐름

API 편집기에서는 Chrome을 켜 둡니다. 실행 중인 API 모델을 다시 읽어 Base/Ours/Theirs를 병합하고, 충돌을 해결한 뒤 최종 내용을 승인해 검증하며 반영합니다. 삭제한 원본은 보이는 복구 폴더로 이동합니다. 결과가 불확실하면 재시도를 막고 상태를 직접 검토합니다. 항목 내용과 구조를 복구하는 방식이며, 일괄 반영의 원자성이나 동기화를 보장하지 않습니다. 실제 사용자 프로필의 API 쓰기는 아직 제한합니다.

기존 파일 방식의 검증 목표는 다음과 같습니다.

1. 최초 스냅샷 Base를 보관하고 작업본 Ours를 편집합니다. 편집 중에는 Chrome을 계속 사용할 수 있습니다.
2. 반영 전 브라우저 작업을 마치고 Chrome을 종료합니다. 강제로 종료하지 않습니다.
3. 최신 원본 Theirs를 다시 읽어 3-way 병합하고 충돌을 직접 해결합니다.
4. 삭제를 포함한 변경 내역을 검토하고, 원본 백업을 검증한 뒤 원본을 재확인해 교체합니다.
5. 파일 검증, Chrome 재시작, 동기화 결과를 구분하고 복원 수단을 유지합니다.

전체 브라우저 흐름은 검증 목표이며 현재 실제 프로필 쓰기 지원을 뜻하지 않습니다. Ego 직접 지원은 미정입니다.

## 언어와 디자인

영어가 기준 언어입니다. 한국어(`ko`), 일본어(`ja`), 중국어 간체(`zh-Hans`) 네이티브 리소스를 포함하며, 언어 선택과 영어 fallback을 로컬에서 기초 확인했습니다. 번역 감수, 전체 접근성·레이아웃 검토, 상세 진단 번역은 남아 있습니다. [현지화 정책](docs/localization.md)을 참고하세요. 중국어 번체는 초기 범위에 포함하지 않습니다.

[독립 HTML 디자인 시안](design/galmuri-prototype.html)은 합성 데이터를 쓰며 새로 고치면 초기화됩니다. 네이티브 런타임이 아닌 디자인 참고 자료입니다. 별도 시안 테스트:

```sh
node --test design/prototype.test.mjs
```

폴더 탐색에는 뒤로·앞으로·상위 폴더 이동과 클릭 가능한 경로가 있습니다. 폴더를 북마크 링크보다 먼저 표시하고 종류를 구분합니다. 일반 폴더는 바로 아래 항목을, 검색은 하위 폴더까지 보여줍니다. 화면의 묶음 표시는 저장 순서를 바꾸지 않으며, 명시적인 순서 변경은 같은 종류의 형제 항목 사이에서 동작합니다.

실행 취소 기록은 앱을 종료하면 사라집니다. 다시 연 뒤에도 반영 전 변경 → 전체 변경 취소…에서 전후 내용을 확인하고 현재 프로필을 Galmuri에 보관된 원본 상태로 되돌릴 수 있습니다. 삭제 항목을 복구하고 추가·수정·이동·순서 변경을 취소합니다. Chrome을 다시 읽거나 쓰지 않으며 다른 프로필은 바뀌지 않습니다.

프로필 관리에서 실제·합성 프로필을 정리할 수 있습니다. 제거 전에 비공개 로컬 JSON으로 작업 공간을 보관하며, 브라우저 파일과 원본 백업은 유지합니다. 새로고침은 평문을 읽고 3-way 병합을 검토한 뒤 Galmuri만 갱신합니다. 이전 작업 공간을 보관하고 기준 원본을 바꾸므로 승인 후 실행 취소 기록은 초기화됩니다. 선택 변경 취소와 삭제 항목별 복구도 영향 범위를 먼저 보여줍니다. HTTP·HTTPS 북마크는 명시적으로 눌렀을 때 기본 브라우저로 엽니다. 원본 직접 쓰기나 실행 중인 브라우저의 최신 상태를 보장하는 기능은 아닙니다.
