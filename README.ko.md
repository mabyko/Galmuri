# Galmuri · 갈무리

**여러 프로필의 북마크를 한곳에서 다듬고, 브라우저에 반영하세요.**

[English](README.md) · 한국어 · [日本語](README.ja.md) · [简体中文](README.zh-Hans.md)

Galmuri는 SwiftUI로 만든 실험 단계의 **macOS 네이티브 북마크 편집기**입니다. 여러 Chrome 프로필의 북마크를 작업본으로 읽어 와 안전하게 편집하고, 앱 밖으로 나가기 전에 모든 변경을 보여 주며, 그사이 브라우저에서 바뀐 내용과 내 편집을 병합합니다.

> **상태: 실험 단계.** 아직 배포용 다운로드는 없고 소스에서 직접 빌드합니다. Galmuri는 실제 Chrome 프로필 파일에 쓰지 않습니다. 지금 변경을 Chrome에 되돌리려면 HTML로 내보내 가져오거나, [실험실](#실험실)의 선택형 확장 경로를 사용합니다.

## 할 수 있는 일

- **Chrome 프로필을 읽기 전용으로 연결합니다.** 원하는 프로필을 고르면 Galmuri가 각 프로필의 사본을 따로 보관하고 원본은 건드리지 않습니다.
- **파일 관리자처럼 편집합니다.** 중첩 폴더, 검색, 여러 항목 이동, 끌어다 놓기, 순서 변경, 같은 주소 모아 보기, 실행 취소를 지원합니다.
- **무엇이 바뀌었는지 보여 줍니다.** ‘반영 전 변경’ 화면에 추가·수정·이동·삭제된 항목이 모두 나옵니다. 선택한 항목만 되돌리거나 전부 취소할 수 있습니다.
- **덮어쓰지 않고 병합합니다.** 새로고침은 브라우저의 북마크를 다시 읽어 내 편집과 3방향 병합합니다. 충돌은 나란히 보여 주고 직접 고릅니다.
- **내보냅니다.** 어느 브라우저에서나 가져올 수 있는 Netscape HTML(프로필 전체 또는 폴더 하나)과 작업 공간 전체의 JSON 백업을 만듭니다.
- **네 가지 언어를 지원합니다.** 영어, 한국어, 일본어, 중국어 간체.

## 아직 하지 않는 일

- 실제 Chrome 프로필 파일에 쓰기. 파일 직접 반영은 앱이 만든 합성 테스트 파일에서만 동작합니다.
- 암호화되었거나 계정 전용인 북마크 저장소 읽기. 평문 `Bookmarks` 파일이 있는 프로필만 지원합니다.
- 동기화, 클라우드 저장, 계정. 모든 데이터는 Mac 안에만 있습니다.
- 서명·공증된 빌드 배포.

## 빌드와 실행

macOS 14 이상, Xcode 명령줄 도구, Swift 6이 필요합니다. 외부 의존성은 없습니다.

```sh
swift test
python3 scripts/check-localization.py
scripts/build-local.sh release
open "build/release/Galmuri.app"
```

스크립트는 임시 서명된 로컬 앱을 만들 뿐, 아무것도 설치하지 않고 Apple 팀을 등록하지도 않습니다. Debug 빌드, 데이터 위치, 일회용 스모크 검사는 [로컬 개발 문서](docs/local-development.md)를 보세요.

처음 실행하면 **Chrome 연결**을 선택합니다. macOS가 브라우저 데이터 폴더 접근을 물을 수 있습니다. Galmuri가 그 단계를 안내하며, 선택한 프로필만 읽습니다.

## 변경을 안전하게 다루는 방법

1. 처음 읽은 북마크를 **Base**로 저장하고, 편집은 별도의 작업본(**Ours**)에서 합니다.
2. 반영하거나 새로고침하기 전에 브라우저의 현재 북마크(**Theirs**)를 다시 읽습니다.
3. 3방향 병합으로 양쪽을 합칩니다. 양쪽에서 모두 바뀐 항목은 충돌로 표시되고 직접 해결합니다.
4. 삭제 항목을 포함한 최종 결과를 검토한 뒤에만 사용합니다.

새로고침 전, 프로필 연결 해제 전, 작업 공간 가져오기 전에는 작업 내용의 로컬 사본을 남깁니다.

## 실험실

설정 → 실험실에는 기본값이 꺼진 스위치 두 개가 있습니다.

- **API 연결 및 편집기.** 작은 Chrome 확장과 앱 안의 도우미가 Chrome을 켜 둔 채로 Chrome의 북마크 API를 통해 북마크를 읽고 편집합니다. 프로필마다 화면에 표시되는 코드로 연결합니다. 일반 연결은 Chrome 쪽에서 읽기 전용이고, 변경 반영은 전용 테스트 환경으로 제한됩니다. 지워진 항목은 삭제하지 않고 복구 폴더로 옮깁니다. [API 설정, 동작, 한계](docs/chrome-api-workspace.md)를 보세요.
- **파일 직접 반영.** `Bookmarks` 파일의 백업·교체·복원이며, Galmuri가 소유한 합성 테스트 파일에서만 동작합니다.

확장은 `bookmarks`, `nativeMessaging`, `storage` 권한만 요청하고 웹사이트 권한은 없습니다. 자세한 내용은 [실험실과 설치](docs/labs.md)에 있습니다.

## 개인정보

Galmuri에는 네트워크 기능, 분석 수집, 계정이 없습니다. 북마크는 Mac 안에서만 읽고 저장합니다. 이슈, 풀 리퀘스트, 테스트 자료에는 실제 북마크, 브라우저 프로필, 백업, 비공개 주소를 넣지 말고 합성 데이터를 사용해 주세요.
