# Galmuri · 갈무리

**複数プロファイルのブックマークをまとめて整理し、ブラウザに反映します。**

[English](README.md) · [한국어](README.ko.md) · 日本語 · [简体中文](README.zh-Hans.md)

Galmuri は SwiftUI で作られた実験段階の **macOS ネイティブのブックマークエディタ**です。複数の Chrome プロファイルのブックマークを作業コピーとして読み込み、安全に編集できます。アプリの外に出る前にすべての変更を表示し、その間にブラウザ側で変わった内容と自分の編集をマージします。

> **状態：実験段階。** 配布用のダウンロードはまだなく、ソースからビルドします。Galmuri は実際の Chrome プロファイルのファイルには書き込みません。現在、変更を Chrome に戻すには、HTML に書き出して読み込むか、[実験室](#実験室)にあるオプションの拡張機能の経路を使います。

## できること

- **Chrome プロファイルに読み取り専用で接続します。** 必要なプロファイルを選ぶと、Galmuri がそれぞれのコピーを別に保持し、元のファイルには触れません。
- **ファイルマネージャのように編集します。** 入れ子のフォルダ、検索、複数項目の移動、ドラッグ＆ドロップ、並べ替え、同じアドレスの一覧、取り消しに対応します。
- **何が変わったかを示します。** 「未反映の変更」画面に、追加・編集・移動・削除された項目がすべて並びます。選択した項目だけを元に戻すことも、すべて破棄することもできます。
- **上書きせずにマージします。** 更新するとブラウザのブックマークを読み直し、自分の編集と 3 方向マージを行います。競合は並べて表示され、自分で選びます。
- **書き出します。** どのブラウザでも読み込める Netscape HTML（プロファイル全体またはフォルダ 1 つ）と、ワークスペース全体の JSON バックアップを作成します。
- **4 つの言語に対応します。** 英語、韓国語、日本語、簡体字中国語。

## まだできないこと

- 実際の Chrome プロファイルのファイルへの書き込み。ファイルへの直接反映は、アプリが作成した合成テストファイルでのみ動作します。
- 暗号化された、またはアカウント専用のブックマークストアの読み取り。平文の `Bookmarks` ファイルがあるプロファイルのみ対応します。
- 同期、クラウド保存、アカウント。すべてのデータは Mac の中だけにあります。
- 署名・公証済みビルドの配布。

## ビルドと実行

macOS 14 以降、Xcode コマンドラインツール、Swift 6 が必要です。外部の依存関係はありません。

```sh
swift test
python3 scripts/check-localization.py
scripts/build-local.sh release
open "build/release/Galmuri.app"
```

スクリプトはアドホック署名のローカルアプリを作るだけで、何もインストールせず、Apple のチームも登録しません。Debug ビルド、データの場所、使い捨てのスモークチェックについては[ローカル開発](docs/local-development.md)を参照してください。

初回起動時に **Chrome に接続**を選びます。macOS がブラウザのデータフォルダへのアクセスを確認することがあります。Galmuri がその手順を案内し、選択したプロファイルだけを読み取ります。

## 変更を安全に扱う仕組み

1. 最初に読み込んだブックマークを **Base** として保存し、編集は別の作業コピー（**Ours**）で行います。
2. 反映または更新の前に、ブラウザの現在のブックマーク（**Theirs**）を読み直します。
3. 3 方向マージで両方を統合します。両側で変更された項目は競合として表示され、自分で解決します。
4. 削除を含む最終結果を確認してから使用します。

更新の前、プロファイルの接続解除の前、ワークスペースの読み込みの前には、作業内容のローカルコピーを残します。

## 実験室

設定 → 実験室には、初期状態でオフのスイッチが 2 つあります。

- **API 接続とエディタ。** 小さな Chrome 拡張機能とアプリ内のヘルパーが、Chrome を開いたまま Chrome 自身のブックマーク API を通じてブックマークを読み取り、編集します。プロファイルごとに画面上のコードでペアリングします。通常の接続は Chrome 側では読み取り専用で、変更の反映は専用のテスト環境に限られます。削除された項目は消さずに復旧フォルダへ移します。[API の設定、動作、制限](docs/chrome-api-workspace.md)を参照してください。
- **ファイルへの直接反映。** `Bookmarks` ファイルのバックアップ・置換・復元で、Galmuri が所有する合成テストファイルでのみ動作します。

拡張機能が要求する権限は `bookmarks`、`nativeMessaging`、`storage` のみで、ウェブサイトへの権限はありません。詳細は[実験室とインストール](docs/labs.md)にあります。

## プライバシー

Galmuri にはネットワーク機能、解析、アカウントがありません。ブックマークは Mac の中でのみ読み取り、保存されます。Issue、プルリクエスト、テストデータには、実際のブックマーク、ブラウザプロファイル、バックアップ、非公開の URL を含めず、合成データを使ってください。
