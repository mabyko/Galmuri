# Galmuri 화면 재설계

2026-10-23 · SwiftUI 네이티브 앱을 위한 화면·인터랙션 초안.

## 계승과 변경

기존 `Tab Library`의 차콜 바탕, 회색 구분선, 폴더 사이드바, breadcrumb, 표 중심 목록을 계승한다. 합성 데이터만 사용하며 기존 `개인/Fluent` 라벨을 실제 Chrome 연결로 재사용하지 않는다. 화면의 프로필과 모든 수치는 예시다.

웹 스타일을 그대로 그리는 대신 macOS의 도구 막대, 선택 행, 시스템 기호, 표, inspector와 시트를 사용한다. 기존 CSS의 `#191919`·`#202020` 톤과 절제된 파랑 강조를 시안에 유지하되 실제 앱은 시스템 다크 색상과 대비를 검토한다. 이번 단계에는 앱 아이콘 제작·Liquid Glass 채택을 포함하지 않는다.

## 정보 구조

- **사이드바:** Galmuri, 연결한 프로필, 현재 프로필의 전체 목록·변경사항·같은 URL, 중첩 폴더, 백업·복원. 하단에 앱 작업본 상태.
- **편집 영역:** 경로와 프로필 → 큰 목록 제목 → 검색·정렬 → 이름/폴더/변경 상태 표 → 선택 동작. 오른쪽 inspector는 선택할 때만 표시.
- **저장 검토:** 목록을 전환해 종료 확인 → 최신 변경·충돌 해결 → 최종 검토. 각 단계에는 한 가지 주 동작. 사이드바에 유지되는 프로필로 저장 대상을 식별.
- **반영 결과/복원:** 파일 반영·재시작·동기화 상태와 원본 백업을 분리. 복원 전 현재 상태 보관과 삭제 영향을 확인.

## 시안의 화면

| 화면 | 행동과 검토할 점 |
| --- | --- |
| 편집 | 프로필·폴더 선택, 검색, 같은 URL 보기, 이름/URL 편집, 선택 이동·제외·되돌리기 |
| 프로필 연결 시트 | 접근 목적과 폴더 선택, 거부 상태·재시도. 실제 OS 권한 UI 대신 시연임을 표시 |
| Chrome 종료 확인 | 편집 중 Chrome 사용 가능, 반영 때 종료 필요. 강제 종료 동작 없음 |
| 병합·충돌 | 합성 예시의 이름 충돌, 삭제 대 수정, 이동·정렬 충돌. 원래/앱/Chrome 값 비교, 선택 전 진행 차단 |
| 최종 검토 | 앱 변경과 유지할 Chrome 변경, 원본 백업, 대상 변경 시 재검토, 반영 전 승인 |
| 반영 결과 | 실제 파일 저장 성공으로 과장하지 않고 시연 완료 표시. 재시작·동기화 검증 대기 분리 |
| 백업·복원 | 백업 내역, 복원 전 변경 차이와 현재 상태 보관, 복원 시연 |

인터랙티브 시안은 미리 준비한 변경/충돌 예시를 사용한다. 실제 병합 계산·Chrome 종료 감지·권한·파일 자동 저장·백업·복원은 수행하지 않는다. 이 구분은 화면 상단과 각 저장 동작에 표시한다. 제공하지 않는 MVP 기능을 동작하는 것으로 가장하지 않는다.

## SwiftUI 구성 제안

사이드바/콘텐츠의 분할 탐색, 선택 가능한 Table, 선택 항목의 inspector, 검색 도구 막대, 편집·연결 시트, 취소 가능한 저장 검토 화면으로 옮긴다. HTML 검토 자료에서는 편집 패널을 다이얼로그로 단순화했고, 네이티브에서는 목록과 함께 보는 inspector를 검토한다. 구체적인 API 가용성과 최소 OS는 [기술 계획](technical-validation.md)에 따라 결정한다.

프로필별 작업본은 앱이 소유하고 선택·검색·열 표시 같은 일시 상태는 화면이 소유한다. 종료·권한·병합·쓰기 상태는 하나의 흐름으로 관리해 서로 모순된 화면이 동시에 열리지 않도록 한다. 병합 계산과 파일 처리는 View body에서 수행하지 않는다.

## 크기·타이포그래피·접근성

desktop 기준 1280×820 안팎에서 사이드바 220px, 나머지는 유동적으로 배치한다. 좁아지면 부가 열을 줄이고 사이드바를 접으며, 핵심 상태와 저장 문구를 잘라내지 않는다. HTML 시안은 대화창의 728px과 320px 폭에서도 흐름을 읽을 수 있도록 재배치한다. 이 반응형 HTML이 iOS 지원을 뜻하지 않는다.

시스템 한글 폰트, 본문 14px 안팎, 표 제목과 보조 정보의 크기·명도 차이로 위계를 만든다. 한국어 어절 줄바꿈과 긴 URL의 비상 줄바꿈을 함께 허용한다. 실제 앱은 시스템 글꼴과 사용자 텍스트 크기를 따른다. 상태를 색상만으로 표현하지 않고 ‘수정/이동/제외’ 같은 이름을 함께 쓴다.

모든 메뉴와 이동은 키보드 대안을 제공한다. 선택 행·포커스 표시를 구분하고, 시트는 제목과 명시적인 취소 동작을 제공한다. 충돌 선택은 radio로 명확하게 표시하며 저장 단계가 바뀌면 제목에 포커스를 옮긴다. 실제 앱에서는 VoiceOver·확대·대량 항목 성능을 별도 검증한다.

## 이번 작업 범위와 검증 기록

변경 범위는 기획·검증 계획·디자인 명세·합성 HTML 시안·시안 테스트·검증 기록이다. 기존 scratch 원본, 실제 북마크 데이터, 전역 규칙, Chrome 설치·프로필은 변경하지 않는다. 기존 앱의 호출자·설정·export 수정은 없으며, 네이티브 앱 생성과 Chrome 어댑터 구현은 다음 단계다.

브라우저 시안의 실제 검사 결과는 `validation.md`에 기록한다. 검증 결과가 없는 항목을 완료로 표시하지 않는다.
